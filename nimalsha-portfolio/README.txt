Nimalsha Shiron - portfolio website
===================================

Files
  index.html                      the whole website (HTML, CSS and JS in one file)
  assets/photo.jpg                your portrait
  assets/project-shadow.jpg       Project Shadow screenshot
  assets/Nimalsha-Shiron-CV.pdf   your CV (the Download CV button uses this)

Run it in VS Code
  1. Unzip this folder and open it in VS Code (File > Open Folder).
  2. Install the "Live Server" extension.
  3. Right-click index.html > Open with Live Server.

Edit it
  - Text, prices and links are plain HTML inside index.html. Use Ctrl+F to find them.
  - Colors are the variables at the top of the <style> block (--bg, --accent, ...).

Put it online (free) with GitHub Pages
  1. On github.com create a PUBLIC repository named  Zerocreator-eng.github.io
  2. Upload index.html and the assets folder to it.
  3. Repository > Settings > Pages > Deploy from a branch > main / (root) > Save.
  4. After a minute your site is at  https://zerocreator-eng.github.io
     (your Nexus Life project stays at /nexus-life/).
